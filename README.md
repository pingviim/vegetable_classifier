# В ходе выполнения задания было сделано следующее:

## 1. Обучение модели CNN
Разработана архитектура CNN без использования предобученных моделей. Модель обучена на предоставленном датасете. 
В коде приведены комментарии, обосновывающие выбор архитектуры и гиперпараметров.

## 2. Оценка модели.
### Проведён анализ динамики функции потерь и метрик обучения. Рассчитаны следующие метрики классификации:
- Accuracy 
- Confusion matrix 
- Precision 
- Recall 
- F1-score
### Представлена интерпретация полученных результатов и сформулированы выводы о качестве модели.

## 3. Использование предобученной модели
- Реализовано решение задачи с использованием предобученной модели компьютерного зрения. 
- Проведена оценка качества предобученной модели, выполнено сравнение результатов с собственной моделью. 
- Сформулированы итоговые выводы.

## 4. Реализация сервиса инференса
### Реализован сервис с использованием FastAPI, содержащий 4 эндпоинта:

GET /ping — возвращает статус сервиса (alive)

GET /health — детальная информация о состоянии сервиса

POST /classify — принимает изображение, возвращает предсказание класса и вероятность

POST /similarity — принимает два изображения, возвращает значение схожести между ними

## Инструкция по запуску
### Для работы с кодом необходимо сделать следующее:
- Склонировать репозиторий ```git clone https://github.com/pingviim/vegetable_classifier.git```
- Создать виртуальное окружение в папке с проектом ```python -m venv .venv```
- Активировать виртуальное окружение ```.venv\Scripts\activate```
- Установить библиотеки с помощью команды ```pip install -r requirements.txt```
- Код готов к работе
### Для обучения модели необходимо сделать следующее:
#### !Обученные веса находятся в models/custom и models/resnet, дальнейшие шаги необходимы для обучения новой модели!
- в файле **config.py** изменить переменную MODEL_TYPE
- Если необходимо обучить кастомную модель - установить значение "custom".
- Если необходимо обучить модель на предобученных весах - установить значение "resnet50".
- Запустить файл **main.py**, во время выполнения кода загрузится датасет и начнется процесс обучения.
- Результаты будут сохранены в папке **runs/дата_и_время_запуска**
### Для запуска FastAPI сервиса необходимо сделать следующее:
- Проверить есть ли веса в папках models/custom и models/resnet
- Если нет, то перейти к предыдущему шагу
- При наличии весов необходимо поменять значение переменной MODEL_TYPE в файле **config.py** на "custom" или "resnet50"
- Далее запустить файл **run_api.py**
#### Сервис запущен, он доступен по адресу **localhost:8000**
